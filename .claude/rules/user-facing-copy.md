# User-Facing Copy Style

Applies to any text an end user actually reads: API error/exception messages, validation messages returned in responses, email and SMS templates, push/socket notification text.

Does **not** apply to code comments, commit messages, log lines, docs, or internal tooling output — write those normally.

Rules:
- Never use em dashes (—). Use a period, comma, or parentheses instead.
- Never use emojis.
- Never overexplain. State the fact or instruction once, plainly. No restating, no "in other words," no padding a sentence with justification it doesn't need.
